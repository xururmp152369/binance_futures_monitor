# Binance 合約監控機器人

自動監控 Binance USDT 永續合約，偵測「4h 拉漲後盤整突破 / 均線反彈」進場訊號，並透過 Telegram Bot 發送通知。可選擇開啟自動下單功能。

## 快速開始

### 1. 建立帳號

```
/register <帳號> <密碼>
```

- 帳號：3 字元以上英數字
- 密碼：6 字元以上
- 每個帳號只能綁定一個 Telegram 帳號

### 2. 登入

```
/login <帳號> <密碼>
```

登入後你的 Telegram 帳號會綁定到此帳號，開始接收策略訊號通知。含有密碼的訊息會在傳送後自動刪除，保護你的密碼不被他人看見。

### 3. 接收訊號

登入後即可自動接收策略告警。不需要其他設定。

### 4. 開啟自動下單（選用）

若需要自動下單，請先完成設定（見 [自動下單設定](#自動下單設定)）。

## 自動下單設定

### 步驟

1. 輸入 `/setup`，Bot 會傳送一份 JSON 設定範本
2. 複製範本，填入你的 Binance API 資訊與交易參數
3. 將填好的 JSON 直接傳送給 Bot
4. 成功後 Bot 會顯示設定摘要確認

輸入 `/myconfig` 可隨時查看目前設定（API Key 只顯示前 4 碼）。

### 欄位說明

| 欄位 | 說明 |
|------|------|
| `API_KEY` / `SECRET_KEY` | Binance Futures API 金鑰（需要期貨交易權限） |
| `STRATEGY` | 觸發下單的策略，可填 `"TYPE1"`（帶量突破）、`"TYPE2"`（均線反彈），或兩者都填 |
| `RISK_TYPE` | 風險計算方式：`0` = 固定投入金額、`1` = 固定損失金額 |
| `RISK_AMOUNT` | 對應 `RISK_TYPE` 的金額（USDT） |
| `RISK_LEVERAGE` | 槓桿倍數（正整數） |
| `MARGIN_TYPE` | 保證金模式：`"CROSSED"`（全倉）或 `"ISOLATED"`（逐倉） |
| `TP_STRATEGY` | 止盈策略，1 ～ 3 組，每組設定盈虧比與平倉比例（%），最後一組自動全數平倉 |
| `ORDER_LIMIT` | 同時持有部位數量上限 |
| `ADD_SAME_SYMBOL` | 同一幣種已有倉位時，是否再次開單加倉 |
| `SYMBOL_BLACKLIST` | 不自動下單的幣種清單，空陣列表示不限制 |
| `ENABLED` | 是否啟用自動下單 |

### 部分更新

不需要每次傳送完整 JSON。若只想修改特定欄位，只傳送你要更改的部分即可，例如：

```json
{"ENABLED": false}
```

```json
{"RISK_LEVERAGE": 10, "ORDER_LIMIT": 5}
```

## Session 說明

- 登入後 Session 有效期為 **30 天**
- 每次與 Bot 互動（任何訊息或指令）都會自動延長 30 天
- 若超過 30 天沒有任何互動，Session 到期，**自動下單將被停止**，Bot 會傳送通知
- 到期後重新 `/login` 即可恢復

### Telegram 帳號遺失或換裝置

使用新的 Telegram 裝置重新執行 `/login <帳號> <密碼>` 即可，舊裝置的綁定會立即失效。

## 注意事項

### API 金鑰安全
- API Key 以加密方式儲存在伺服器
- 建議只開放「期貨交易」權限，勿開放提款
- 若 API Key 洩漏，請立即在 Binance 後台廢止舊 Key 並重新設定

### 密碼安全
- 不要在公開群組使用 `/register` 或 `/login`，請在與 Bot 的私聊中操作
- Bot 會自動刪除含密碼的訊息，但在私聊環境下更安全

### 自動下單風險
- 自動下單功能依策略訊號執行，策略本身有一定誤判率
- 請確認設定中的風險金額、槓桿、止盈止損符合你的風險承受度
- 程式僅在偵測到訊號時下單，不保證盈利
