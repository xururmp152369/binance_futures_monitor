# ADR-003: 死亡叉策略的 48H 時效性設計

## 狀態
Accepted

## 背景

死亡叉策略的 Layer 2 觸發條件是「日線 close 跌破 EMA200」。但跌破 EMA200 這件事本身並不罕見，問題在於：

- 若一個幣種已在 EMA200 以下持續運行了很久，再次「跌破」EMA200 的意義很低（已是空頭趨勢中的延伸）
- 反之，若是剛從 EMA200 上方跌破，代表趨勢剛剛轉弱，空頭訊號更具時效性

另外，ALERT 窗口的有效時間也是個設計問題：窗口太長會讓陳舊的跌破繼續觸發進場；太短則可能錯失 1H 進場機會。

---

## 決策

### Layer 2 時效性：48H 回溯窗口（`DC_MAX_ROLLBACK_HOURS`）

進入 ALERT 之前，先向前掃描歷史日線，找到最近一根 `close > EMA200` 的日線。若距離當根超過 48H，則視為「跌破不新鮮」，不進入 ALERT。

```python
time_diff_h = (candle_ts - last_above_ts) / 3600
if time_diff_h > DC_MAX_ROLLBACK_HOURS:  # 48H
    return  # 略過，不進入 ALERT
```

### ALERT 窗口：48H 監控期（`DC_ALERT_WINDOW_HOURS`）

進入 ALERT 後，只在 48H 內偵測 1H 信號。到期後退回 WATCHING，等待下次日線跌破。

---

## 理由

**48H 回溯限制的設計**：日線 K 棒的週期是 24H，48H 約等於「前一根日線還在 EMA200 上方，這根才跌破」的情境。這樣篩選出的是「剛發生的結構性轉弱」，而不是已在空頭趨勢中的延伸下跌。

**ALERT 窗口 48H 的設計**：1H 進場信號（拒絕/吞噬）通常在跌破後 1-2 天內出現。若超過 48H 仍無信號，代表市場在此價位附近沒有出現空頭確認，等待下一次跌破再判斷。

**兩個 48H 值使用相同常數的考量**：Layer 2 回溯和 ALERT 窗口都設 48H，來自同一個直覺：「距上次高於 EMA200 約 2 根日線」的時間範圍。未來若需要個別調整，可以拆成不同常數。

---

## 後果

- **正面**：避免在已持續的下跌趨勢中重複觸發訊號
- **正面**：ALERT 窗口到期自動退回，不會永遠掛在 ALERT 等候
- **負面**：若行情跌破 EMA200 後緩慢下行超過 2 天才出現 1H 信號，會錯失進場機會
