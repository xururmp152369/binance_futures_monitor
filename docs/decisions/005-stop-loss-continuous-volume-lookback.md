# ADR-005: Type 1 止損回掃採用連續性而非全段最低點

## 狀態
Accepted

## 背景

Type 1 進場訊號確認後，需要計算止損位置。止損的目的是找到「最近一批買盤集中進場的低點」，以此作為多頭失效的判斷線。

有兩種設計方案：
- **方案 A（全段掃描）**：找當前 4h 開盤後，所有放量 K 棒中的最低 low
- **方案 B（連續掃描）**：從當根往前，找**連續**放量 K 棒的最低 low，遇到第一根量能不足就停

---

## 決策

採用**方案 B（連續掃描）**，遇到第一根量能不足的 K 棒即停止。

```python
stop_loss = low  # 起始：當根 15m low

for i in range(len(ohlc_list) - 2, -1, -1):
    prev = ohlc_list[i]
    if prev[0] < current_4h_open_ms:
        break                              # 超出 4h 邊界，停止
    if prev[5] > lookback_threshold:
        stop_loss = min(stop_loss, prev[3])  # 放量：納入止損
    else:
        break                              # 量能不足：停止（連續性中斷）
```

---

## 理由

**連續性代表「同一波買盤」**：放量突破通常是一群連續的強勢 K 棒構成，中間若出現量能衰退的 K 棒，代表該批買盤已告一段落。止損應設在「最近這一波買盤」的最低點，而不是整段 4h 任意時點的最低點。

**方案 A 的問題**：若 4h 開始時有一根放量下跌 K（例如開盤後的洗盤），其低點會被納入止損計算，造成止損位置偏低（離進場價太遠），風險報酬比惡化。

**`LOOKBACK_VOLUME_MULT = 2.5×`**：回掃的放量門檻比突破門檻（3.5×）低，這是刻意的設計——突破本身需要更強的量能，但回掃止損只需要辨識「有在放量」的 K 棒即可。

---

## 後果

- **正面**：止損位置更貼近進場時機點，反映最近這一波量能聚集的真實支撐
- **正面**：防止過早的放量 K 棒（可能是反向的）干擾止損計算
- **負面**：若突破前只有一根放量 K（量能不連續），止損直接等於當根 low，可能位置偏緊
