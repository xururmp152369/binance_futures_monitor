# ADR-006: Method C — TRACKING 階段延伸超過門檻後允許更換基準K棒

## 狀態
Accepted

## 背景

ADR-002 的 Method B 只設計給「已盤整夠久、隨時可進場」的階段。在那之前的追蹤階段（原拉漲K棒觸發後、持續創新高的過程中），若出現更強的新拉漲K棒，系統會忽略，導致：

1. 基準K棒資料（含 Taker Buy Ratio）無法更新，進場驗證的參照過時
2. 追蹤階段出現的強勢K棒無法成為新的進場錨點

**實際案例（CLOUSDT，2026-06-11）：**
- 6/11 08:00 拉漲K棒觸發，最高 0.14499
- 6/11 ~ 6/12 00:00 持續創新高，仍在追蹤階段
- 6/12 08:00 出現另一根強勢拉漲K棒，最高延伸至 0.20746（從原K棒最高漲幅約 43%）
- 現行邏輯：忽略 6/12 這根，Taker Buy Ratio 仍用 6/11 的資料

---

## 決策：新增 Method C

### Gate 條件（開啟評估的門檻）

從原基準K棒的最高點（多單）或最低點（空單）到目前已創到的極值，漲跌幅超過 `METHOD_B_RELAXED_THRESHOLD`（預設 10%）：

```
多單：(consolidation_high - pump_candle_high) / pump_candle_high * 100 > METHOD_B_RELAXED_THRESHOLD
空單：(pump_candle_low - consolidation_low)   / pump_candle_low  * 100 > METHOD_B_RELAXED_THRESHOLD
```

動態計算，不需要新的 state 欄位。

### 新K棒資格條件

1. 本身是有效拉漲K棒（漲幅 ≥ 動態門檻，量能 ≥ 3× 均量）
2. 成交量 ≥ **當下 pump_candle_volume** × `METHOD_B_VOLUME_RATIO`（0.8）
   - ⚠️ 比較基準是「當下記錄的基準K棒成交量」，不是任何中間延伸K棒

不需要漲幅比較優勢（不需要 1.1 倍），Gate 本身已代表原K棒被大幅超越。

### 觸發後更新內容

| 項目 | 處理方式 |
|------|----------|
| 基準K棒所有資料（含 Taker Buy Ratio） | 全部換成新K棒 |
| 止損線底部（多單用 low，空單用 high） | 換成新K棒的對應值（往有利方向移動） |
| 突破目標頂部 | 取 max(舊頂部, 新K棒頂部)，只進不退 |
| 盤整計時起點 | 重置為新K棒時間 |

### 適用情境

| 情境 | 適用 Method C |
|------|---------------|
| 創新高的拉漲K棒，Gate > 10% | ✓ |
| 未創新高的拉漲K棒，Gate > 10% | ✓ |
| 任何K棒，Gate ≤ 10% | ✗ |
| 盤整等待進場階段（READY）出現強勢K棒 | ✗（由 Method B 處理）|

---

## Method B（READY 階段）保持不變

Method C 不影響 Method B 的任何邏輯，兩者分別適用不同階段。

---

## 理由

- **Gate 10% 條件**防止頻繁重置，確保只在原K棒「早已被大幅超越」時才更換參照
- **不需漲幅優勢比較**：已延伸 10%+ 代表原K棒代表性已大幅下降
- **止損線往有利方向移動**符合直覺：價格已大幅移動，保留遙遠的舊底（或舊頂）作為廢棄線意義不大
- **成交量比較基準固定為當下基準K棒**：防止拿延伸K棒的量（通常較小）作為標準，造成門檻失真

---

## 後果

- **正面**：基準K棒能反映最新的強勢拉漲K棒，Taker Buy Ratio 等進場前驗證條件更具代表性
- **負面**：Method C 觸發後，盤整計時重置，可能延後進入等待進場階段的時間
